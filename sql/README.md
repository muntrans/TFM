# Consultas SQL

`imputaciones_mes.sql` es la consulta al MES (Olanet, SQL Server) que genera `data/raw/imputaciones.csv`. Devuelve una fila por imputación de tiempo: la máquina (nodo), la orden, el material, la fase, los minutos reales, depreparación y de producción, el porcentaje de dedicación y la incidencia, entre otros campos.
